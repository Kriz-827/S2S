# Malayalam Sign Language to Speech

An AI-based system that converts Malayalam Sign Language gestures into speech using Computer Vision and Deep Learning.

## Features

- Real-time sign recognition
- Malayalam speech generation
- MediaPipe hand tracking
- LSTM-based gesture classification

## Tech Stack

- Python
- TensorFlow
- OpenCV
- MediaPipe
- NumPy
- gTTS
